# Concept images – brand, possible UI, gameplay

Twelve images generated with Higgsfield (Recraft V4.1, palette-constrained to `specs/design/tokens.css`)
to show what the product could look like. They are concepts to react to, not assets. Nothing here
ships without being rebuilt properly.

## Brand

| File | What it shows | Notes |
|---|---|---|
| `01-logo-sheet.svg` | Wordmark + a bolt-and-pickaxe mark in a chamfered square; three lockups on coal and on off-white | A credible starting point. The mark needs a real drawing pass; the wordmark should be set in Barlow Condensed, not the generic grotesque here. |
| `02-key-art.webp` | Poster: "Four blocks. One mine. Closes forever." over an amber stripe and a cyan progress bar | The tagline candidate. Bar-with-ticks as the brand's signature device works. |
| `03-season-card.webp` | Social card: "The mine opens" with countdown and four ticker tiles | Close to shippable structure for announcements. Numbers under tickers are placeholders. |
| `04-merch.webp` | Enamel pin, RIG coin, sticker | Shows the mark holds up as a physical object. |

## Possible UI

| File | What it shows | Notes |
|---|---|---|
| `05-ui-phone-mine.webp` | Phone at night: light block card over a dark rig card, cyan progress bar, amber Overclock | An interesting variant: a light block card *inside* the dark mine. Worth a real mockup as an option against the all-dark mine view. |
| `06-ui-rig-room-concept.webp` | Alternate direction: isometric rig room with a HUD | The "game-y" alternative to the dashboard mockups. Rigs as objects that visibly overclock. Higher build cost; strongest for retention and shareability. |
| `07-ui-burn-sheet.webp` | Overclock confirmation sheet with burn amount, heat gauge, "confirm burn" | Matches brief §5 purchase sheet. Typo in the render ("permamently"); the real copy is "burned permanently". |
| `08-ui-block-found-notification.webp` | Lock-screen notification: "Block 2 found · TSLAx" | The push notification is a core surface because blocks are found on no schedule. |
