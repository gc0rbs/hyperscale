# Design working files

`artboards/*.dc.html` and `artboards/canvas.json` are the mockups described in
`docs/11-DESIGN-BRIEF.md`, generated by `build-artboards.py` from the tokens in
`specs/design/tokens.css`. Edit the generator, re-run it, and re-save the design canvas.

Canvas: https://claude.ai/code/artifact/5708ed3f-3a81-4b3f-bf4e-1247d4770adb (private; share from the page).

Phase 3 (app build) copies markup from these artboards rather than inventing layout.
